## 🔄 Workflow Demonstration Guide

### As Patient (patient@test.com)
1. **Login** → See dashboard with stats
2. **Find Doctors** → Search "cardio" or "abhi" → See Dr. Abhi
3. **Book Appointment** → Select date/time → Book
4. **View Appointments** → See completed and upcoming appointments
5. **View Prescriptions** → See prescribed medicines
6. **Pharmacy** → Search medicines → Add to cart → Place order
7. **My Orders** → View order status
8. **Medical History** → See complete history

### As Doctor (abhi@doctor.com)
1. **Login** → See dashboard with appointment stats
2. **Appointments** → View all appointments
3. **Complete Consultation** → Add diagnosis → Issue prescription
4. **Profile** → Update specialization, fees, availability
5. **Analytics** → View appointment trends and statistics

### As Pharmacist (pharmacist@test.com)
1. **Login** → See pharmacy dashboard
2. **Orders** → View pending orders
3. **Verify Order** → Check prescription → Verify
4. **Update Status** → Dispatch → Add tracking number
5. **Medicines** → View inventory → Update stock

### As Admin (admin@test.com)
1. **Login** → See admin dashboard with all stats
2. **Users** → View all users → Approve doctors → Activate/deactivate
3. **Appointments** → View all appointments across system
4. **Orders** → Monitor all pharmacy orders
5. **Analytics** → View charts and trends
